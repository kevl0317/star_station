# 星际信号站

独立项目仓库：https://github.com/kevl0317/star_station.git 。项目无需依赖同级的其他游戏目录，克隆后可直接用 Node.js 启动。

保留太阳系美术、星图、25 张知识卡与章节航线，玩法按用户要求恢复为更新前的 25 关版本。

## 启动

双击 `打开星际信号站.cmd`，或在本目录执行 `npm start`。浏览器访问 http://127.0.0.1:4174/ 。需要 Node.js 18 以上。测试：`npm test`。

## 玩法

信号从屏幕左右两侧沿不同路线移动，允许多个信号同时出现。点击符合当前规则的信号，飞出前未接收的目标计为漏接。后期恢复旧版相似干扰、随机星尘遮挡、左右/三区扫描和分段加速。第 22 关保留原本的单信号分区规则。

关卡时长、信号数量、移动速度、目标规则、通关阈值和星级由 `src/flight-levels.mjs` 定义。通常 60 秒，章节验收和第 24 关为 50 秒。取消新版固定中央接收窗和逐个闪现的 0.2 秒缓冲。

空格或 Esc 暂停；点击恢复按钮继续。切换后台自动暂停。正确点击立即移除目标、不能重复得分；连续正确只计点击目标。飞船恢复居中，命中曲线从不可见接收边界发出。前三关 5 秒练习保留。

观测图按本关目标数分格，每正确接收一个目标恢复一格；格子铺满图像，不保留空格。知识卡只在每关首次结束时展示一次（无论是否达标），重玩及刷新后不再自动展示；通关后仍可在图鉴查看收藏。保留已有星级、解锁进度和收藏，旧存档已结束的关卡不重复展示。存档键继续使用 `star-signal-station-v2`，规则版本为 4；旧历史记录仍保留。测试入口 `/?test=1` 隔离正式进度。

## 文件

- `src/flight-levels.mjs`：更新前的关卡玩法配置与示例。
- `src/levels.mjs`：将旧玩法配置与现有太阳系任务、观测天体关联。
- `src/engine.mjs`：信号调度、判断、计分及存档。
- `src/renderer.mjs`：移动轨迹、飞船接收曲线。
- `src/observatory.css`：参考山海食谱铺的信息层次，统一首页章节卡、按钮、关前规则、图鉴与结算面板的展示。
- `src/astronomy.mjs`、`assets/solar-art-v1/`：知识卡和生成美术。
- `ART.md`：素材来源与提示词记录。

尚未部署公网、接入账号云存档或微信小游戏 SDK。

`docs/` 保留本机需求文档，不纳入 Git；游戏运行不依赖该目录。

开发检查：`signal-art-preview.html` 预览飞行信号，`knowledge-art-preview.html` 预览全部知识卡；`node scripts/check-assets.mjs` 检查素材缺失与未使用文件。

2026-09-19 界面整理：首页按观测场景、章节选择、本章五关分层展示；太阳系星图保留在可展开区域。支持浏览未开启章节的任务，开始关卡仍遵守原有解锁顺序。手机章节条保留选中位置，结算在中小屏采用单列。关卡配置、计分、练习时序和存档格式未变。
