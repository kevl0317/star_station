# 知识卡影像

配图信息和逐图署名见 `credits.json`，下载地址见 `downloads.json`。
照片和效果图以本地 JPEG / PNG 提供，保持来源影像的颜色、画幅、标识；网页仅等比缩放，不裁切。NASA 动态图像服务提供的版本可能已经缩小。

- K05：嫦娥六号表取月壤的实验室照片，来自 Li 等人的研究（DOI: 10.1093/nsr/nwae328），通过 Wikimedia Commons 分发，CC BY 4.0。不是阿波罗或嫦娥五号样品。
- K11、K12：国家航天局供图、新华社发布的祝融号火星地貌和着巡合影，北京国际科技创新中心转载。保留原图水印与署名；该来源未声明 Creative Commons 授权，不将其标为自由版权素材。
- K13：MRO/HiRISE 的火卫一 PIA10368 与火卫二 PIA11826；后者原图包含两个视角，均为火卫二。保留原始拼图。
- K17：朱诺号 PIA23606，NASA/JPL-Caltech/SwRI/MSSS 数据，Kevin M. Gill 处理，源页声明 CC BY；增强色影像。
- K18：朱诺号 PIA21384，NASA/JPL-Caltech/SwRI/MSSS 数据，Sergey Dushkin 处理；源页链接 JPL Media Usage Guidelines，增强色影像。
- K19：卡西尼号 PIA10505，NASA/JPL/Space Science Institute。显示土星 A 环局部，不是单颗冰粒的显微照片。
- K24：新视野号冥王星近自然色合成影像，NASA/JHUAPL/SwRI/Alex Parker。

来源链接随图显示，照片可点开大图。研究照片的 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 和 [JPL 媒体使用指引](https://www.jpl.nasa.gov/jpl-image-use-policy/) 以各来源说明为准。

K06 八大行星轨道、K20 行星环是 `src/knowledge-art.mjs` 中的原创 SVG 教学示意。行星纹理沿用游戏素材；不把示意图标为真实照片。银河系图是结构概念图，非从银河系外拍摄的照片。

运行 `python scripts/fetch-knowledge.py` 可按已记录的地址重新下载照片。

K25 已改用 NASA/JPL-Caltech 的 PIA10748 银河系结构科学示意图（2008 年发布）。`milky-way.jpg` 是无标注版，`milky-way-annotated.jpg` 是官方英文标注版；网页中文位置标注按官方 Sun 标记对应，不改变源图片。此图为依据观测绘制的科学概念图，不是银河系外部实拍。

K04 改用中国空间技术研究院提供、国家航天局发布的鹊桥二号效果图（10539868.png），以及国家航天局发布的嫦娥六号移动相机在 2024-06-03 拍摄的着陆器与上升器合影（10543450.jpg）。效果图与实拍分开标注，原图与标识保留。下方仅保留通信关系连线。来源未声明 CC 授权，不标为自由版权素材。
